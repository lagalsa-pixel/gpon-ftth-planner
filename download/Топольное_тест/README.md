## Условные знаки (Task 50)

- **ЦУ · OLT** — тёмный бейдж с красной рамкой: здание с антенной и сигнальными
  дугами, красная табличка «OLT»; подпись «ЦУ · OLT — центральный узел села»
- **ОРШ-N** — уличный шкаф цвета зоны: вентиляционные щели, **номер зоны на
  шкафе**, дверцы с ручками, цоколь; подпись «ОРШ-N / N ДХ»
- **Кабели на общих трассах** (Task 51) — разводятся параллельными линиями
  с межосевым промежутком (пучок центрируется по оси трассы): магистраль
  (сплошная, цвет зоны) + фидеры ЦУ→ОРШ (пунктир, каждая зона своей полосой)
- **Дропы из одной муфты к одному дому** — параллельные жёлтые линии
  с промежутком; начало точно у муфты, заход точно в точку ДХ

## Настройки качества детекции (Task 51, config params)

- `hh_cv_vlm_gate=True` — VLM-гейт «крыша или дерево» для CV-кандидатов
  (кэш `work/topolnoe/vlm_roof_gates.json`, переживает прогоны и обрывы квоты)
- `hh_fences_enable=True` — строящиеся ДХ по ограждениям: ≤15 соток,
  контур замкнут/разомкнут, но образует прямоугольник, разрывы до 15 м
  (здания/деревья) допускаются; `hh_fence_vlm=True` — VLM-гейт «пустой
  огороженный участок» (топ-60 кандидатов по уверенности)
- эвристики детектора: `detect_roofs(gray_v_min=110)` — расширенный шифер;
  отсев круглых пятнистых зелёных крон; анти-лес для участков (доля тёмных px)

## Кратчайшие трассы (Task 52, config params)

- `net_detour_eps=0.30` + `net_detour_min_m=100` — детур-гард ствола:
  в граф объединения добавляются кратчайшие пути терминалов, чей маршрут
  по дереву длиннее (1+eps)× кратчайшего и перерасход > 100 м; маршрут
  становится точным, общие участки продолжают разделяться
- `net_drop_shortest=True` — дропы кратчайшими уличными путями от ближайшей
  по дорогам муфты (дроп — выделенное волокно, следовать дереву не обязан);
  для дропов > 120 м — промежуточные муфты (~100 м от ДХ) с продлением
  ствола по этой же кратчайшей трассе; пустые муфты чистятся

## Примечания

1. VLM-вердикты кэшируются (`vlm_verdicts.json`, `vlm_roof_gates.json`) и
   воспроизводятся детерминированно; обрыв квоты не теряет прогресс.
2. Кадр покрывает центр села (205 из 311 ДХ); полная сеть — на мозаике
   (work/topolnoe_test/work/topolnoe/network.json).
3. Число ДХ снизилось с 402 до 311: гейт удалил ложные CV-ДХ (деревья),
   которые ранее завышали счётчик; добавлены 6 строящихся ДХ по ограждениям.
